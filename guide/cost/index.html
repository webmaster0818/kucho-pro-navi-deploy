業務用エアコン費用相場ガイド

業務用エアコンの費用相場は、機器代金と工事代金を合わせて5馬力以下で50万〜70万円、6馬力以上で100万〜150万円です（1セットあたり・税込）。これはダイキンが公表している目安で、5馬力以下は一般事務所で70㎡以下、6馬力以上は80㎡以上が目安とされています。新規の取り付けと交換（入れ替え）を区別せずに集計された数値です。ダイキンはこの金額を「設置費用の目安」としており、6馬力以上では80万〜90万円が2番目に多い価格帯としています。

交換の場合は、既設機の撤去・廃棄や冷媒の処理に数万円〜数十万円が別にかかることがあります。配管が長い場合や、室外機の設置にクレーンが必要な場合も費用が上がります。

出典：ダイキン工業「業務用エアコンの価格相場は？工事費込みでいくらが目安？」（スカイエアの目安。2023年4月〜2024年3月の成約案件の販売価格をもとに集計。2026年10月30日確認）

実際の費用は、機器のサイズ・機種タイプ・設置環境・業者によって大きく異なります。馬力ごとの本体価格と標準工事費は、出典とあわせて坪数×馬力×費用 早見インデックスに掲載しています。以下では、規模別の目安、費用の内訳、修理費の目安、補助金をご説明します。

室内機の形と設置費用

ダイキンは、室内機の形と設置方法が設置費用に影響するとしています。設置費用が高い順は次のとおりです。

  1. 天井埋込カセット形：重い室内機を天井裏に取り付けるうえ、新設で天井に開口がない場合は開ける工事が必要なため、ほかの形より最も高額になる場合があります。
  2. 天井吊形：天井に穴をあけずに設置できますが、重い室内機を天井から吊るす作業が必要なため、天井埋込カセット形に次いで高くなります。
  3. 床置形：本体が重いため壁掛形よりは費用がかかりますが、天井吊形よりは抑えられます。
  4. 壁掛形：工事の手順が家庭用と大きく違わないため、業務用エアコンの中で設置費用を最も抑えられます。

出典：ダイキン工業「業務用エアコンの価格相場は？工事費込みでいくらが目安？」（2026年10月30日確認）。費用を抑える方法と依頼先は業務用エアコンの費用を抑える方法と依頼先の公式情報でご案内しています。

規模別・修理の費用について

店舗の広さ別の設置費用や、ガス補充・部品交換などの修理費用は、機種・馬力・台数・設置条件・故障の内容で大きく変わります。金額は業者の見積もりで確認してください。見積もりでは、機器代・基本工事費・配管や電気の追加工事・既設機の撤去費用が分けて記載されているかを確認すると比較しやすくなります。

費用を抑える5つのポイント

  1. 1.相見積もりを3社以上取る — 業者によって機器の仕入れ値や工事の範囲が異なるため、同じ条件で比較します
  2. 2.室内機の形を検討する — ダイキンは、壁掛形が業務用エアコンの中で設置費用を最も抑えられるとしています（設置できる場所かは現地調査で確認します）
  3. 3.補助金・税制優遇を活用する — 国の省エネ・非化石転換補助金（設備単位型）の補助率は、補助対象経費の1/3以内（GX設備単位型トップ性能枠の更新は1/2以内）です（SIIの4次公募の公募要領・2026年11月4日確認）。自治体の補助は上の「使える補助金・助成金」をご覧ください
  4. 4.必要台数・馬力を正確に計算する — 過剰な能力にならないよう、専門家の助言を受けることをおすすめします
  5. 5.リースや分割払いを活用する — 初期費用を分散し、資金繰りの負担を軽減できます

よくある質問

業務用エアコンの費用相場は、工事費込みでいくらですか？

ダイキンの公表値では、機器代金と工事代金を合わせた1セットあたりの目安（税込）は、5馬力以下（一般事務所で70㎡以下が目安）で50万〜70万円、6馬力以上（同80㎡以上）で100万〜150万円です。2023年4月〜2024年3月にダイキンへ問い合わせがあり成約した案件の販売価格をもとにした数値で、配管の長さや室外機の設置場所によって変わります（2026年10月30日に公式サイトで確認）。

交換（入れ替え）の場合も、同じ相場ですか？

ダイキンの目安価格は、新規の取り付けと入れ替えを区別せずに集計されています。入れ替えの場合は、既設機の撤去・廃棄費用、冷媒配管の洗浄費用、冷媒の処理費用が別にかかることがあり、ダイキンは機器の種類や台数により数万円〜数十万円としています。

工事費が目安より高くなるのは、どのような場合ですか？

ダイキンは、室内機と室外機の距離が遠い場合（配管が長くなる）、室外機を屋上や壁面に設置する場合（クレーン等が必要）、新設で三相200Vの電源工事が必要な場合、入れ替えで撤去・廃棄が発生する場合、古い建物でアスベストの事前調査が必要な場合を挙げています。

馬力ごとの本体価格は、どこで確認できますか？

業務用エアコン専門店の公式サイトに、馬力・形状ごとの本体価格が掲載されています。当サイトでは、専門店3社の掲載価格（天井カセット形4方向・本体のみ）を、税込・税別などの条件と確認日とあわせて早見インデックスにまとめています。工事費・追加費用は設置条件で変わるため、現地調査のうえで複数社の見積もりを比較してください。

出典：ダイキン工業「業務用エアコンの価格相場は？工事費込みでいくらが目安？」（2026年10月30日確認）
