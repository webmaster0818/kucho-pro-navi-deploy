業務用エアコンの設定温度｜事務所の室温の基準とリモコンの設定範囲

最終更新：2026年11月20日（厚生労働省（事務所衛生基準規則・施行通達）と三菱電機の取扱説明書で確認）

事務所で業務用エアコン（空気調和設備）を使う場合、事務所衛生基準規則により、室の気温を18℃以上28℃以下、相対湿度を40%以上70%以下にするよう努める必要があります。下限は令和4年4月1日の改正で17℃から18℃に引き上げられました。基準は「室温」で、リモコンの設定温度ではない点に注意してください。 三菱電機の取扱説明書では、冷房時は室内と室外の温度差を5℃以内にするのが最適とし、冷房の設定温度を1℃上げると約10%の電力が節約できるとしています。

事務所衛生基準規則の室内環境の基準（空気調和設備を設けている場合）

項目基準補足
室の気温18℃以上28℃以下（努力義務）空気調和設備を設けている場合。令和4年4月1日施行の改正で下限を17℃から18℃に引き上げ
相対湿度40%以上70%以下（努力義務）空気調和設備を設けている場合
気流0.5m/s以下室に流入する空気が特定の労働者に直接、継続して及ばないようにする

事務所衛生基準規則 第5条第2項・第3項と、厚生労働省の施行通達（基発0301第1号）より当サイトが整理しました。2026年11月20日確認。

リモコンで設定できる温度の範囲と、規則の室温18〜28℃との関係

運転モード設定できる温度（三菱電機の例）規則の室温18〜28℃との関係（当サイトの比較）

送風設定できない—

三菱電機 パッケージエアコン 室内ユニット取扱説明書（PL-ZRP・EA3形ほか）の設定温度範囲と、事務所衛生基準規則の室温の範囲を当サイトが比べました。設定はMAスマートリモコンで0.5℃、ワイヤレスリモコンで1℃単位です。設定温度範囲制限が設定されている場合は範囲が狭くなります。2026年11月20日確認。

設定温度を決めるときの確認事項

  • •温度計・湿度計で、実際の室温と湿度が18〜28℃・40〜70%に入っているか
  • •吹出しの風が特定の人に直接、継続して当たっていないか（風向の調整）
  • •冷房時に室内外の温度差が大きくなりすぎていないか
  • •フィルターが目詰まりしていないか（三菱電機は、目詰まりは冷房・暖房能力を下げ電力のムダ使いになるとしています）

設定温度を下げても冷えない場合は業務用エアコンが冷えないときの確認事項、複数台の設定温度をまとめて管理する方法は空調管理システム、電気代の目安は業務用エアコンの電気代でご説明しています。学校の教室の基準は学校用の業務用エアコンをご覧ください。

よくある質問

Q.設定温度を28℃にすれば、室温は28℃になりますか？

A.設定温度と実際の室温は同じになるとは限りません。事務所衛生基準規則の基準は「室の気温」で、リモコンの設定温度ではありません。日射や人の多さ、機器の能力で室温は変わるため、温度計で室温を測って確認してください。

Q.設定温度を1℃変えると、電気代はどのくらい変わりますか？

A.三菱電機の取扱説明書は、たとえば冷房のとき設定温度を1℃上げると約10%の電力が節約できるとしています。あわせて、冷房運転では室内と室外の温度差を5℃以内にするのが最適で、冷やしすぎは健康によくなく電力のムダ使いにもなると案内しています。

Q.従業員が勝手に設定温度を変えないようにできますか？

A.三菱電機の取扱説明書では、設定温度範囲制限を設定すると、リモコンで変えられる温度の範囲を狭くでき、範囲を超えて設定しようとすると「設定温度制限中」と表示されると案内しています。設定方法はリモコンの取扱説明書で確認してください。集中管理システムで設定温度を管理する方法もあります。

Q.空調設備がない事務所にも18〜28℃の基準はありますか？

A.規則の努力義務は空気調和設備を設けている場合ですが、厚生労働省の施行通達は、それ以外の場合でも冷暖房器具を使用することなどにより、事務所の室の気温を18度以上28度以下にすることが望ましいとしています。
